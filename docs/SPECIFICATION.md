# 產品與功能規格

## 產品目標

讓 HTC RE 使用者可在 Android 8–15 手機上完成相機連線、遠端拍攝、媒體瀏覽與檔案取回。

## 導覽架構

1. **連線**：無線狀態、裝置偵測、連線、背景連線及斷線提醒。
2. **拍攝**：拍照、開始及停止錄影。
3. **相簿**：瀏覽相機檔案、選取並下載。
4. **串流**：RTSP 即時預覽；後續版本實作。
5. **裝置**：韌體、序號、儲存空間、介面及偵錯設定。

## 功能需求

- **FR-01 探索**：顯示 BLE 掃描狀態、結果與錯誤；掃描須在設定時間內停止。
- **FR-02 複合連線**：BLE 後建立 Wi‑Fi Direct group；分別顯示 BLE、P2P、HTTP 與 RTSP 狀態；可檢查手機藍牙及 Wi‑Fi 開關。
- **FR-03 拍攝**：拍照與錄影命令均提供忙碌、成功及失敗回饋，避免重複命令。
- **FR-04 相簿**：分頁取得媒體，顯示縮圖、類型、時間、大小與下載狀態；欄位待硬體確認。
- **FR-05 下載**：支援 Range 續傳、進度、取消與重試；以暫存檔完成驗證後再命名。Android 10+ 最終版本使用 MediaStore。
- **FR-06 裝置**：顯示名稱、序號、韌體、容量與網路狀態；無資料時顯示「未知」。
- **FR-07 串流**：管理 live view session 與 RTSP 播放；背景或中斷時釋放資源。
- **FR-08 背景連線**：使用者可啟用前景服務維持 process 內的連線監看，並隨時關閉。
- **FR-09 斷線提醒**：使用者可獨立啟用或關閉斷線通知。
- **FR-10 外觀**：提供深色及淺色主題，保存使用者選擇並維持文字對比。
- **FR-11 偵錯**：裝置頁可開啟 Console、清除及透過系統文件選擇器匯出文字 Log；Log 不包含密碼與媒體識別。

## 非功能需求

- 觸控目標至少 48dp；正文對比至少 4.5:1；狀態不只靠顏色。
- 耗時 I/O 不得在主執行緒執行。
- 連線、HTTP 與下載具備 timeout、取消及資源清理。
- 不將 Wi‑Fi passphrase、序號或媒體內容寫入一般日誌。
- 螢幕旋轉、背景切換與系統回收後須恢復可解釋狀態。

## 目前不在範圍

- 社群平台登入或發文。
- Dropbox、Google Drive 或其他雲端硬碟。
- 韌體更新與回復原廠設定。
- 未經使用者操作的背景同步。
